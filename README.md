# Ударний FPV-коптер — онлайн-курс (Victory Drones × ARM Drones)

Внутрішня чернетка для погодження. Не для публікації.

- `index.html` — відкриває останню версію (`versions.json`).
- `v1/` — версія 0.1. Після публікації не змінюється; нова версія = нова папка `v2/`.
- `v1/content/` — вступ і модулі (`m01.js` …). Питання — лише надані автором курсу.
- `media/` — відео уроків (пізніше переїде в Cloudflare R2: змінити `VIDEO_BASE` у `v1/app.js`).

Поступ поки зберігається в браузері (демо). Групи, вхід за нікнеймом і панель адміністратора — наступний етап (Supabase).
